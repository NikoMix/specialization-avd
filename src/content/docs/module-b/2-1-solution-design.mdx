## What the Auditor Checks

The auditor verifies that a **High-Level Design (HLD) document** was produced
and signed off, covering all the major AVD design pillars.

**Typical questions:**
- Show me the HLD.
- Walk me through the host pool topology decision.
- Why pooled vs personal? Why this identity model? Why this profile storage?
- How is the image managed and refreshed?

## Evidence Guidance

### Host pool topology decision

| Persona | Topology | Why |
|---|---|---|
| Knowledge workers | Pooled multi-session (Win 11 Enterprise multi-session) | Best cost & density; stateless |
| Power users / developers | Personal | Persistent state, custom installs, GPU possible |
| Call centre / shift workers | Pooled multi-session, time-based scaling plan | High density, predictable working hours |
| Regulated / isolation | Single-session pooled or personal | Per-user isolation, audit boundary |

### Identity design

- **Entra-joined + Intune** is the default
- **Hybrid join** when on-prem AD-bound apps must work (Kerberos / NTLM)
- Document the MFA enforcement, CA policy targeting AVD, RBAC roles for AVD
  admins, and PIM for elevated roles

### Profile storage decision tree

- &lt; 1,000 users, standard latency tolerance → **Azure Files Premium** (Kerberos auth)
- &gt; 1,000 users OR latency-sensitive OR very high IOPS → **Azure NetApp Files**
- Always pair FSLogix **profile container** + **Office container** split for OneDrive / Outlook OST

### Networking essentials

- **RDP Shortpath for managed networks** enabled
- AVD service endpoints / private endpoints documented
- Egress firewall rules listed (per AVD URL allow-list)
- DNS resolution for FSLogix storage (AD / Entra Kerberos)

## Common Gaps

| Gap | Remediation |
|---|---|
| HLD missing BCDR section | Add paired-region host pool + profile replication pattern |
| Image strategy says "we use Marketplace" with no refresh plan | Add Azure Image Builder pipeline and a monthly refresh cadence |
| No rationale for pooled vs personal | Add a 1-page decision record per persona |
| No customer sign-off on HLD | Obtain sponsor sign-off before production deployment |
