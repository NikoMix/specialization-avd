## When to use this

In the first or second customer call, before scoping any design work. The
output feeds directly into [Discovery](../discovery-workshop/) and into
the audit control [B.1.1 Workload Assessment](../../module-b/1-1-workload-assessment/).

## Inputs you need from the customer

| # | Input | Source | Format |
|---|---|---|---|
| 1 | Approximate user count by persona | EUC team | Verbal / spreadsheet |
| 2 | Current desktop platform | IT | Verbal |
| 3 | Application inventory | IT / App owners | Excel / SCCM / Intune export |
| 4 | Identity model | Identity team | Verbal |
| 5 | Network constraints | Network team | Verbal / diagram |
| 6 | Security & compliance constraints | Security team | Policy doc |

## Questionnaire

### 1. Business context

- What is driving this AVD conversation now? (RDS refresh, Citrix cost,
  workforce flexibility, M&amp;A, regulated, other)
- Who is the business sponsor (CIO / Head of Workplace)? Who is the IT
  sponsor (EUC owner)?
- Is there a board-level deadline?
- What is "done" from the business perspective?

### 2. User personas

For each distinct persona, capture:

| Persona | Approx users | Apps used | Profile type | Working hours | Region(s) | Devices | Special needs |
|---|---|---|---|---|---|---|---|
| Knowledge worker | | M365, Edge, Teams, LOB | Pooled multi-session | | | BYOD + corporate | |
| Power user | | + Visio, Project, BI tools | Personal | | | Corporate | |
| Developer | | + IDE, Docker, GPU | Personal | | | Corporate | GPU? |
| Call centre | | M365 + CRM | Pooled multi-session | Shift | | Thin client | |
| Regulated | | LOB only | Single-session pooled | | | Locked-down | Audit boundary |

### 3. Application inventory

| App | Vendor | Licensing | Per-user / shared | MSIX available? | Compatibility tested? | Decision (MSI / MSIX / AppAttach / Intune / M365 / streamed) |
|---|---|---|---|---|---|---|

For at least the top 20 apps. Tag any that are **blockers** (incompatible,
COM-bound, GPU-bound, very large installer).

### 4. Image strategy

- Marketplace + customisation, or gold image?
- Build pipeline preference (Azure Image Builder, Packer, manual)?
- Refresh cadence target (monthly, quarterly)?
- Who owns the image post-handover?

### 5. Identity posture

- Entra ID tenant + sync model (cloud-only, hybrid)?
- MFA enforcement model?
- Conditional Access policy patterns?
- Hybrid join requirement (any LOB app needing on-prem AD Kerberos / NTLM)?
- AVD admin model (PIM eligible, named admins, JIT)?

### 6. Profile storage

- Current profile storage (FSLogix? UPM? roaming profiles? local only)?
- Profile size budget (GB per user typical / max)?
- OneDrive Known Folder Move active?
- Latency tolerance (knowledge worker vs trader desk)?

### 7. Network

- Where do users connect from (regions, % office vs remote)?
- Existing Azure VNets / ExpressRoute?
- RDP Shortpath blockers (firewalls, NAT, UDP egress)?
- DNS for FSLogix storage (AD / Entra Kerberos)?
- Egress firewall — can we add AVD service URLs to allow-list?

### 8. Security & compliance

- Regulated industry constraints (e.g. PCI, HIPAA, FINRA, GDPR specifics)?
- Data residency requirements (region pinning, sovereign cloud)?
- Endpoint isolation requirements (no copy/paste, no local print, no USB
  redirection)?
- Audit logging retention requirements?

### 9. Scale targets and timeline

- Wave 1 user count and date?
- Steady-state total users?
- M&amp;A integration deadline?
- Source-system retirement deadline (RDS / Citrix / Horizon contract end)?

### 10. Operations

- Who will operate AVD post-handover (in-house EUC team / MSP)?
- What is their current Microsoft skill level?
- What ITSM tool integrates with alerts?
- What hypercare duration does the customer expect?

## Output: customer-ready deliverable

A 5–10 page **Qualification Summary** that becomes input to the
[Discovery Workshop](../discovery-workshop/) and the
[B.1.1 Workload Assessment](../../module-b/1-1-workload-assessment/) evidence.
