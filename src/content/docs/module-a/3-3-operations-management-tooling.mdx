## What the Auditor Checks

The auditor verifies that the AVD environment has **operations management
tooling deployed and actively used** — at minimum Azure Monitor, Log
Analytics, and the AVD Insights workbook — with alerting and review cadence.

**Typical questions:**
- Show me the Log Analytics workspace receiving AVD data.
- Open AVD Insights and walk me through it.
- What alerts fire and who responds?

## Evidence Guidance

### Diagnostic data coverage

At minimum these data sources should flow into the Log Analytics workspace:

| Resource | Logs |
|---|---|
| Host pools | Checkpoint, Error, Management, Connection, HostRegistration, AgentHealthStatus |
| Workspaces | Checkpoint, Error, Management, Feed |
| Application groups | Checkpoint, Error, Management |
| Session hosts (VMs) | Performance counters via AMA; Windows Event Logs |
| FSLogix storage (Azure Files) | Storage diagnostic logs |
| Scaling plans | Autoscale activity |

### AVD Insights

Deploy the workbook from **Azure Monitor → Insights Hub → Azure Virtual
Desktop**. Confirm the data sources page shows green for the relevant host
pools. Walk the auditor through:

- **Connection Diagnostics** — failed connections by reason
- **Host Performance** — CPU / memory / disk by session host
- **User Input Delay** — perceived performance
- **Utilisation** — sessions vs. capacity

### Alert examples

| Alert | Threshold | Action |
|---|---|---|
| Host pool capacity > 85% | 15-min window | Notify ops; scaling plan also reacts |
| Session host agent unhealthy | Any | Page on-call |
| FSLogix Profile Container fail event | Any | Ticket to EUC engineer |
| Logon time P95 > 30s | 1-hour window | Notify ops |

## Common Gaps

| Gap | Remediation |
|---|---|
| Workspace exists but only a subset of diagnostics are flowing | Re-check diagnostic settings on every host pool, workspace, app group |
| AVD Insights deployed but no real data | Wait at least 7 days after enabling diagnostics; redo the screenshot |
| Alerts exist but go to a shared mailbox no-one watches | Route to a real action group (on-call, Teams channel, ITSM) |
| No ops review meeting | Schedule a recurring weekly / monthly review and capture an agenda |
